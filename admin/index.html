GitHub 미연결

1. GitHub 연결

저장하면 GitHub 저장소에 바로 커밋됩니다. 토큰은 이 브라우저에만 보관되며 서버로 전송되지 않습니다.
토큰 발급: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 대상 저장소 선택 → Repository permissions에서 Contents: Read and write 부여. 공용 PC에서는 사용하지 마세요.

2. 검토보고서

매거진 페이지 하단 카드 목록입니다. 링크를 비워두면 “준비 중”으로 표시됩니다.

3. 매거진 발행호

가장 위에 있는 호가 최신호로 노출됩니다.

4. 저장

GitHub에 저장은 data/magazine.json 을 커밋합니다. 연결 전이라면 파일로 내려받기로 받아 직접 올릴 수 있습니다.

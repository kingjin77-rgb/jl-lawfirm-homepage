# 고객사 로고

로고 파일을 이 폴더에 두고, `corporate.html` 의 해당 카드에서
`.cli__mark` 안의 `<span>...</span>` 을 아래처럼 바꾸면 표시됩니다.

```html
<span class="cli__mark"><img src="assets/img/clients/파일명.svg" alt=""></span>
```

- 권장 형식: SVG (없으면 배경이 투명한 PNG, 높이 200px 이상)
- 표시 크기: 높이 44px, 최대 너비 150px 안에서 자동 축소
- `alt` 는 빈 값으로 둡니다. 바로 아래 회사명이 이미 글자로 있어 중복 읽힘을 막기 위함입니다.

## 사용 전 확인

타사 로고는 상표이므로 **고객사에서 받은 파일과 사용 동의**가 있는 것만 씁니다.
홈페이지에서 임의로 내려받아 쓰지 않습니다.
관공서 상징(경기도·산림청 등)은 기관별 사용 지침이 따로 있어 사전 확인이 필요합니다.
동의 절차가 끝나기 전까지는 현재의 글자 표식을 그대로 두면 됩니다.

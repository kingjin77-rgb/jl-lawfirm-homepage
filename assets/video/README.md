# 메인 배경 영상

메인 화면 맨 위에서 배경으로 도는 영상입니다.
**파일이 있는 것만 골라 자동으로 순환**합니다. 넣거나 빼는 것만으로 개수가 바뀝니다.

| 파일 이름 | 장면 | 상태 |
|---|---|---|
| `hero-city.mp4` | 도시 전경 | 있음 |
| `hero-office.mp4` | 법무법인 사무실 | 없음 |
| `hero-consult.mp4` | 변호사 상담 장면 | 없음 |

- 하나만 있으면 그 하나만 계속 재생됩니다.
- 둘 이상이면 9초마다 다음 영상으로 넘어갑니다.
- 하나도 없거나 재생이 막히면 스카이라인 그림이 대신 나옵니다.

## 파일 규격

- 형식 MP4 (H.264), 소리 없음
- 크기 1920×1080, 길이 8~15초, 이어 붙여도 티가 안 나게 끝과 시작이 비슷하면 좋습니다
- 용량 한 편당 3MB 이하 — 넘으면 첫 화면이 느려집니다
- 화면 왼쪽에 글자가 올라갑니다. 왼쪽 1/3에는 중요한 피사체를 두지 마세요
- 너무 어두운 영상은 피합니다. 배경을 밝게 쓰고 글자 쪽만 살짝 눌러 읽히게 해 두었습니다

## 만들 때

드론 촬영이나 힉스필드 생성 모두 이 규격에 맞추면 그대로 들어갑니다.
파일명을 위 표대로 맞춰 이 폴더에 넣으면 코드 수정 없이 반영됩니다.

## 게시 전 확인

외부에서 받은 영상은 **상업적 이용이 허용된 것인지 확인한 뒤** 올립니다.
사람이 식별되는 장면은 초상권 동의가 필요합니다.
직접 촬영본이나 생성물을 쓰는 것이 가장 안전합니다.
